# Task Manager Full Stack

Sistema de gerenciamento de tarefas com autenticação JWT.

## Tecnologias

- React
- Node.js
- Express
- MySQL
- JWT

## Funcionalidades

- Cadastro
- Login
- Logout
- CRUD de tarefas
- Rotas protegidas

## Como executar

### Backend

```bash
npm install
npm start
```

### Frontend

```bash
npm install
npm run dev
```
